# قارئ بيانات البطاقة المصرية — Android

مشروع Android أولي لقراءة النص من صورة بطاقة باستخدام Tesseract OCR (عربي + إنجليزي).

## الخصوصية
- المعالجة تتم داخل الهاتف، ولا يوجد إرسال للصور أو البيانات إلى خادم.
- التطبيق لا يطلب صلاحية الإنترنت.
- الحفظ في مساحة التطبيق الخاصة.
- لا ترفع صور بطاقات حقيقية أو أرقامًا قومية إلى GitHub.

## بناء APK
1. ارفع الملفات إلى المستودع حسب المسارات الموضحة في PROJECT_LAYOUT.yml.
2. أنشئ ملف GitHub Actions في المسار `.github/workflows/build-apk.yml` وانسخ إليه محتوى ملف `DOTgithub__workflows__build-apk.yml`.
3. افتح Actions وشغّل Build Egyptian ID Reader APK.
4. نزّل Artifact باسم Egyptian-ID-Reader-debug بعد نجاح البناء.

هذا إصدار تأسيسي؛ راجع النص المستخرج يدويًا. زر الكاميرا الحالي يستقبل صورة معاينة صغيرة؛ للحصول على دقة أعلى اختر صورة كاملة من المعرض.
